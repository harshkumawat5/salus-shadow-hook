## What-if: provenance-gated v2 (tuned on this same sample)

Suppressing a firing when every target is the agent's own (created this session / untracked) would leave 22 firings, all true positives, down from 276. This is by construction the rubric's own line, so it needs a held-out sample before anyone quotes it as precision.
